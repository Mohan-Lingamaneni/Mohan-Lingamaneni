## Featured Projects

### ✈️ [Airline Operations Intelligence](https://github.com/Mohan-Lingamaneni/airline-operations-intelligence)

End-to-end analysis of U.S. flight operations using Bureau of Transportation Statistics data. The project transforms raw flight records into reproducible datasets and uses Python, SQLite, and advanced SQL to evaluate airline, airport, route, time-pattern, and delay-cause performance.

**Focus:** Operational KPIs · Data quality · SQL analytics · Reproducible analysis  
**Stack:** Python · pandas · SQL · SQLite

### 🚚 [Shipping Intelligence: Invoice Reconciliation](https://github.com/Mohan-Lingamaneni/Shipping-Intelligence-mini-project)

Python-based shipping analysis that compares quoted and billed carrier costs, flags invoice overcharges, and summarizes UPS and FedEx performance across spend, invoice variance, on-time delivery, and damage incidents.

**Focus:** Invoice variance · Anomaly detection · Carrier performance · Cost reconciliation  
**Stack:** Python · pandas · CSV
